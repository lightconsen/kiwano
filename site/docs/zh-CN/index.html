Kiwano 文档

安装、Agent 接管、路由策略与完整命令参考——Kiwano 本地网关的中文文档。

快速上手

Kiwano 位于你的编码 Agent 与 AI 供应商之间:供应商注册一次,本地网关跑在 127.0.0.1,所有 Agent 都指向这一个端口。本页从安装带到第一条被计量的 请求。Key 永远不离开你的机器。

Agent 接管

接管是让 Agent 走本地网关的方式:Kiwano 改写 Agent 自己在其 $HOME 下的配置文件,改写前先备份,关闭接管时按字节还原。不注入代理二进制,不替 你导出环境变量——Agent 照常读自己的配置,发现网关就在那里。

策略与限额

每个 Agent 的路由是一个有序候选队列——绑定到它的供应商们。策略决定 下一个请求由哪个候选服务;队列的其余部分是本次尝试中途失败时的重放顺序。 本页覆盖策略、花费限额,以及订阅计划的用量读取。

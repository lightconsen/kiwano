Features

网关底座 × 供应商目录

既不是纯切换工具,也不是云端网关:本地负责路由与计量,Hub 目录帮你选型。

供应商管理

添加、切换、删除供应商配置;路由支持 failover / roundrobin / timewindow / quota 策略,当前项一键生效。

Agent 一键接管

Claude Code、Codex、Gemini CLI 等一键指向本地网关;关闭开关即还原原始配置,随时反悔。

本地网关

单端口常驻 127.0.0.1:8317,协议归一化 anthropic / openai / gemini,逐请求路由、故障转移与计量。

用量仪表盘

请求、token、费用、延迟的 7 天趋势,按供应商与 Agent 归因;明细可下钻到每一次请求。

Provider 货架

Hub 目录聚合 177 家供应商,按官方 / 聚合 / 第三方 / 免费筛选,价格透明,看中即添加。

cc-switch 导入

Screens

How it works

三步,从此告别手改配置文件

Agent 的 base_url 一次性指向网关,之后所有切换都只是路由变更,即时生效、无需重启。

01

添加供应商

从货架一键添加,或自定义端点;API Key 存入本机钥匙串,永不上传。

02

接管你的 Agent

一键把 Claude Code / Codex / Gemini CLI 指向 127.0.0.1:8317,原配置自动备份。

03

随便切换

列表里点一下即完成切换:Agent 配置不再改动,只变网关路由,故障自动兜底。

strategies

四种路由策略,坏节点也兜得住

每个 Agent 绑定一组候选供应商,策略决定这一次请求谁来处理——网关逐请求执行,调整即时生效。

failover

故障转移

按优先级排好候选队列:主供应商故障或超时,自动切到下一家;恢复后流量自动回主路。

A B C
roundrobin

轮询分发

请求在候选供应商之间轮流分配,把用量和压力摊到多家,谁也不至于超载。

timewindow

时间窗

为每家候选设定本地时段:深夜走套餐、白天走按量;跨零点窗口自动回绕,无匹配时落到兜底候选。

00:00 08:00 24:00
quota

配额切换

为候选设定消费 / 请求上限,触顶自动切下一家;新周期配额自动复位,花费不再失控。

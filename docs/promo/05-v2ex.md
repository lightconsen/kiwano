## 正文

```
自己写了一个 Rust + Tauri 的桌面应用 Kiwano,想分享给同样被多 Provider / 多 Agent
配置文件折磨的人。

一句话:**把 Key 留在自己机器上,让所有编码 Agent(Claude Code、Codex、Gemini CLI、
Cline、Kimi Code、Qwen Code 等 14 个)都指向本地 `127.0.0.1` 的一个端口,并且
知道每个请求真实花了多少钱。**

为什么写它:

- 我的 Key 散在 GUI、终端、配置文件三处;Provider 定价是张没人记得的表;
- 一个 Provider 挂了,意味着半天 copy-paste;
- 记账靠月底查账单,晚了。

所以拆成三层:

**App 管 Key** —— 只读的本地 SQLite,目录 0700 / 文件 0600,只有你的用户能读;
无遥测、无埋点,更新检查只拉一个静态 JSON manifest。

**网关管路由** —— 协议归一(OpenAI 兼容的 Provider 也能喂给 Claude Code;Gemini
原生 API 第三种协议直通放行),策略有 single / failover / roundrobin / timewindow /
quota——除了 single,失败的请求会自动换下一个候选重放,不会原样甩回给你。

**货架管价格** —— Hub 上 24 个 Provider(23 个官方 + 聚合 OpenRouter)的条件同步,
离线可用;按 provider × agent 归因的用量与成本、quota 环、成本告警(还有月内
"斜率要超限"的预测告警,不是事后记账)。

信任:每个发布都带 SHA256SUMS 和可验证的构建溯源,不信任镜像也能验:

    gh attestation verify Kiwano_x64.dmg --repo lightconsen/kiwano

macOS 已签名公证;Windows 还没做代码签名(SmartScreen 会提示,已知短板)。
服务器上也能跑,无 GUI,一条命令,用户级 systemd 服务、免 root:

    curl -fsSL https://hub.kiwano.cc/install.sh | sh

许可证 GPLv3+,部分模块移植自 cc-switch(MIT,署名见 THIRD-PARTY-NOTICES),
支持 `kiwano import cc-switch` 一键迁移。

演示视频（30 秒）: https://youtu.be/M0pO79Wlx-s
下载: https://kiwano.cc  |  仓库: https://github.com/lightconsen/kiwano

求 star、求 issue(哪个 Agent 配置在真实环境里不对,我改);也欢迎拍砖——
什么策略还没覆盖、什么计价你没看懂。
```
